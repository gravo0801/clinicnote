Day 11. 흉통: ACS red flag, 의원에서 할 것과 바로 보낼 것

작성일 2026-08-19 · Adult Primary Care Daily
핵심 원칙
의원의 목표는 ACS 확진이 아니라, 의원에서 안전하게 배제할 수 없는 환자를 지체 없이 definitive care가 가능한 곳으로 보내는 것이다.
119 우선
지속되는 전형적 흉통, 불안정 vital, 심한 호흡곤란/저산소증, 실신, aortic syndrome·PE 의심이면 119를 먼저 호출하고 ECG는 가능하면 동시에 시행한다.
진료실 사고방식: Rule-in보다 risk recognition → disposition이 우선. 정상/비진단적 초기 ECG 한 장으로 ACS가 배제되지 않으며, troponin·CXR·추가 채혈을 기다리느라 전원을 늦추지 않는다.

1. 첫 3분 triage

  1. onset, 현재 지속 여부, 지속시간.
  2. 압박감/조임/무거움, 안정 시 발생, 운동 유발, 팔·턱·등 방사, diaphoresis, dyspnea, N/V, syncope/presyncope.
  3. BP/HR/RR/SpO2/의식상태.
  4. shock appearance, pulmonary edema, 심한 빈맥/서맥, 저산소증.
  5. ACS 외에 acute aortic syndrome, PE, tension pneumothorax 동시 스크리닝.
  6. red flag면 검사 계획보다 disposition을 먼저 결정: 119 → 가능하면 ECG → handoff.

2. 바로 응급실/119를 강하게 고려할 소견

범주실전 red flag
ACS현재 지속되는 압박성 흉통, 새로운 안정 시 흉통, 반복/악화되는 통증, 방사통, diaphoresis, dyspnea, N/V, syncope/presyncope, known CAD + 새로운 증상.
불안정 상태저혈압, shock appearance, 의식변화, 심한 저산소증, pulmonary edema, 심한 빈맥/서맥 또는 불안정 부정맥 의심.
Aortic syndrome갑작스런 최대강도 흉통/등통증, pulse/BP asymmetry, 새 신경학적 결손, 새로운 AR 의심.
PE갑작스런 dyspnea + pleuritic pain, hypoxemia/tachycardia, unilateral leg swelling, 최근 수술/부동/암/VTE history.
Pneumothorax갑작스런 호흡곤란 + 일측 호흡음 현저 감소, hemodynamic compromise.

3. 의원에서 할 검사 vs 전원을 늦추는 검사

즉시 할 수 있으면 시행
V/S + SpO2, focused history/PE, 12-lead ECG. 단, red flag가 있으면 이송 준비와 병행.
전원을 늦추면 하지 않음
troponin 결과 대기, 반복 채혈, CXR/기타 영상 대기, 장시간 observation, “검사 다 해보고 보내기”.

Normal ECG ≠ ACS exclusion. 정상/비진단적 초기 ECG라도 임상적으로 ACS가 배제되지 않으면 응급실 평가가 필요하다.

4. 약물/처치 실전

  • 산소는 routine이 아니라 저산소증/호흡부전이 있을 때 사용.
  • ACS가 의심되고 aspirin 금기·활동성 출혈이 없으며 acute aortic syndrome이 의심되지 않는 상황에서는 aspirin을 고려할 수 있으나, 투여 여부 때문에 이송을 늦추지 않는다.
  • 위장약·진통제 반응으로 ACS를 배제하지 않는다.
  • 불안정 환자는 의원에서 관찰하지 않는다.

5. KCD 실무

R07.4상세불명의 흉통. 확진 전 symptom code 후보.
R07.2 / R07.8전흉부통 / 기타 흉통. 실제 기록에 맞춰 사용.
I20.x / I21.x협심증/급성심근경색을 단순 의심만으로 확정 상병처럼 사용하지 말고 실제 근거와 최종 진단에 맞춘다.

6. 법적 리스크를 줄이는 차팅

면책 문구보다 당시 판단 과정이 보이게 기록.
① onset/지속 여부 ② 핵심 red flag ③ V/S ④ 위험감별 ⑤ 의원에서 안전하게 배제할 수 없는 이유 ⑥ ER/119 권고 및 설명 ⑦ 실제 이송/거부 결과.

7. 환자가 119 이송을 거부할 때

ACS 가능성을 배제할 수 없어 119 구급차를 이용한 즉시 응급실 이송을 강하게 권고함.
이동 중 급격한 상태 악화, 치명적 부정맥, 심근경색 및 사망 가능성을 설명함.
환자는 설명 내용을 이해하고 의사결정능력이 있는 상태이나 119 이송을 거부함.
자가운전은 하지 말 것을 설명하고, 보호자 동행 및 증상 악화 시 즉시 119 요청하도록 재차 설명함.
거부 사유: ____________________
보호자 설명 여부/성명: ____________________
설명 시각: ____ / 퇴실 시각: ____ / 퇴실 당시 상태: ____________________

Refusal form 한 장 자체가 면책을 의미하지 않는다. 설명 내용, 의사결정능력, 구체적인 거부 내용과 대안 제시를 사실대로 기록한다.

8. 의원 운영용 FAST TRACK

접수에서 “가슴이 아프다/조인다/답답하다”, “숨이 차면서 가슴이 이상하다”, “팔·턱까지 아프다”, “식은땀이 난다”는 표현이 나오면 대기시키지 않는다.

즉시 진료실/처치실 → V/S·SpO2 → 원장 평가 → red flag면 119 먼저 → ECG는 가능하면 동시에.
