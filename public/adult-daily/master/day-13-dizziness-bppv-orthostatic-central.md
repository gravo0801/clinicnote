# ClinicNote Adult Daily D13

## 어지럼: BPPV, 기립성저혈압, 중추성 red flag

> 최종 PDF를 기준으로 복원한 master 원본입니다. PDF가 배포 기준 산출물입니다.

### 즉시 응급/뇌졸중 평가
- 새로운 편측 마비/감각저하, 복시, 구음·연하장애, 시야결손
- 심한 gait/truncal ataxia, 새 심한 두통/목통증, 지속 구토, 의식변화
- 급성 지속성 어지럼에서 central 또는 equivocal bedside finding
- 저혈압, 실신, 심각한 부정맥/저산소증

### 1. TiTrATE로 먼저 분류
- Acute vestibular syndrome: 수시간-수일 지속되는 급성 지속성 어지럼
- Spontaneous episodic: 분-시간 반복, 뚜렷한 trigger 없음
- Triggered episodic: 특정 머리 위치/일어나기에서 수초-수분 - BPPV, orthostatic hypotension

### 2. 첫 3분 triage
1. BP/HR/SpO2/혈당, 의식, 혼자 걸을 수 있는지 확인
2. 지속성/반복성/triggered pattern 분류
3. 신경학적 증상, 새 두통/목통증, 새 청력저하 확인
4. 기립혈압, 안진/안구운동, 보행 확인
5. 약물, 탈수, 출혈, 부정맥 단서 확인

### 3. 핵심 문진
- 정확한 시작시점과 지속시간, 반복 빈도
- 머리 위치 변화, 누웠다 일어나기, 목 움직임과 연관
- 복시, 구음장애, 연하장애, 편측 약화/감각저하
- 새 청력저하/이명, 두통/목통증
- 구토, 보행장애, 실신/흉통/두근거림
- 항고혈압제, 이뇨제, 진정제, alcohol, 탈수/출혈

### 4. 진찰 루틴
- 활력징후, 기립혈압, glucose
- eye alignment, spontaneous/gaze-evoked nystagmus, EOM
- cranial nerve, limb coordination, strength/sensation
- gait/truncal stability
- 전형적 triggered positional dizziness이면 Dix-Hallpike

### 5. HINTS와 영상검사의 안전한 사용
- HINTS는 **급성 지속성 AVS + 자발안진** 환자에서 숙련자가 시행하는 검사
- 짧은 체위성 어지럼에 적용하지 않음
- 비숙련 HINTS 음성만으로 posterior circulation stroke를 배제하지 않음
- central/equivocal finding 또는 TIA/stroke 우려면 응급 MRI/MRA 경로

### 6. BPPV 실전
- 전형: 특정 머리 위치 후 수초 잠복, 1분 이내 회전성 어지럼
- Posterior canal BPPV: Dix-Hallpike에서 torsional upbeating nystagmus
- 1차 치료: Epley canalith repositioning
- 전정억제제는 장기 관행 처방을 피하고 심한 오심에서 짧게 고려

### 7. 기립성저혈압
- 누워 안정 후 BP/HR -> 서서 1분·3분 측정
- 3분 이내 SBP 20 mmHg 또는 DBP 10 mmHg 이상 감소 시 합당
- 탈수/출혈, 이뇨제, alpha blocker, nitrate, 항고혈압제, 진정제, 자율신경병증 확인

### 8. 검사
- POC glucose, CBC, 전해질/Cr, ECG, 필요 시 TSH
- 영상은 신경학적/중추성 의심에 맞춰 선택하고 전형적 BPPV에 일률 시행하지 않음

### 9. KCD
- R42: 원인 미확정 어지럼
- H81.1: BPPV
- I95.1: 기립성 저혈압

### 10. 처방과 추적
- BPPV: 약보다 repositioning maneuver가 중심
- 기립성저혈압: 원인 약물/volume status 교정, 낙상 안전교육
- 중추성 가능성, 새 신경학적 소견, 심한 보행장애는 즉시 의뢰

### 11. 환자 설명
- 어지럼의 느낌보다 지속시간과 유발자세가 더 중요합니다.
- 말이 어눌해지거나 한쪽 힘이 빠지거나 혼자 걷기 어렵거나 새 심한 두통이 생기면 즉시 응급실로 가십시오.
- BPPV는 약으로 눌러두기보다 이석정복술로 치료하는 것이 핵심입니다.
