D03. 당뇨 초진

1차진료 검진 이상 KCD E11.x v2 · 2026.05
1줄 요약: 당뇨 초진 = 확진 + 응급 배제 + 병형 감별 + 합병증 스크리닝 + 치료/교육 + 추적예약

교육용 초안입니다. 실제 처방/청구는 환자 상태, 병원 프로토콜, 최신 진료지침, 심평/EDI 기준을 확인하세요.

1. 초진에서 먼저 가르는 4가지 질문

질문핵심 판단
Q1. 당뇨가 맞나?진단기준 충족 여부와 재확인 필요성을 판단한다.
Q2. 오늘 응급인가?DKA/HHS, 탈수, 의식변화, 감염, 급성 심혈관 사건을 먼저 배제한다.
Q3. 2형으로 봐도 되나?1형/LADA, 췌장질환, 약제성, 내분비 질환을 감별한다.
Q4. 이미 손상된 장기가 있나?눈, 콩팥, 신경/발, 심혈관 합병증을 초진부터 스크리닝한다.
검진표 HbA1c 6.6%만 보고 "약만 시작"하지 않는다. 증상, 이전 수치, 빈혈/CKD/수혈, 약제, 체중 변화, 케톤/탈수까지 확인한다.

2. 진단 기준 & 한국 국가검진 흐름

검사당뇨 기준해석 포인트
HbA1c6.5% 이상NGSP 표준화. 빈혈/용혈/수혈/CKD에서 실제 혈당과 어긋날 수 있다.
공복혈당(FPG)126 mg/dL 이상8시간 이상 금식 후 정맥혈. 검진 전날 야식/음주 확인.
OGTT 2시간200 mg/dL 이상임신/경계 등 특수상황에서 선택적으로 고려.
무작위혈당 + 증상200 mg/dL 이상 + 다뇨/다음/체중감소탈수/의식변화 동반 시 당일 응급 평가 우선.
  1. 국가검진 공복혈당 100+ 또는 회사검진 HbA1c 이상 소견이면 우리 병원에서 FPG+HbA1c 재확인.
  2. HbA1c 5.7-6.4% + FPG 100-125이면 당뇨전단계: 생활중재 + 3-6개월 추적.
  3. HbA1c 6.5% 또는 FPG 126 이상이면 명백한 고혈당 증상이 없는 경우 다른 날 재확인 원칙.
  4. 다뇨/다음/체중감소가 명백하면 당일 확진 가능. 단, 급성 위험 배제 후 치료 시작.

3. 레드 플래그 — 당일 놓치면 안 되는 위험 신호

범주의심 단서당일 행동
DKA / HHS오심/구토/복통, 탈수, Kussmaul 호흡, 의식저하, 매우 높은 혈당케톤+전해질+산증 확인 → 응급실
1형/LADA 의심마른 체형, 빠른 체중감소, 케톤, 젊은 발병, 자가면역질환 병력C-peptide/GAD항체 → 내분비 의뢰
심한 감염/발 병변발 궤양, 봉와직염, 괴사, 말초혈관질환 의심항생제/영상/혈관평가 → 응급/상급 의뢰
급성 심혈관/신경흉통, 호흡곤란, 신경학적 결손, 실신당뇨 평가보다 응급 평가 우선

4. 초진 오더 세트

목적검사메모
진단 확인HbA1c, FPG 또는 무작위혈당검진표 날짜, 검사기관, 공복 여부 확인.
약제 안전성Cr/eGFR, AST/ALT, 전해질, CBCMetformin/SGLT2i 시작 전 기준 확보.
심혈관 위험지질(TC/LDL/HDL/TG), 혈압, BMI스타틴·혈압 관리 계획 동시 수립.
신장 합병증소변 ACR, eGFR, 요검사ACR 단회 이상 시 반복 확인 필요.
급성 위험(해당 시)소변/혈중 케톤, bicarbonate심한 고혈당, 체중감소, 구토/탈수 때.
합병증 의뢰안과 의뢰, 발(10g monofilament), ECG"나중에"가 아니라 초진 루틴으로 넣어 누락 방지.

5. 첫 치료 결정 로드맵

단계판단
0. 응급 여부케톤/산증/탈수/의식저하/흉통 → 외래 처방 전 응급 평가.
1. 병형 확인전형적 2형 vs 1형/LADA/췌장성/약제성 감별.
2. A1c + 증상A1c·혈당·증상·체중감소·케톤 → 단독/병합/주사 결정.
3. 동반질환ASCVD/HF/CKD/비만/고령/저혈당위험/비용 반영.
4. 추적 예약1-4주(부작용/혈당) + 3개월(HbA1c)을 초진 당일 예약.
상황초기 접근
HbA1c 목표 근접, 무증상생활중재 4주 관찰 후 Metformin(다이아벡스엑스알 500mg bid) 시작.
HbA1c 7.5-9%초기 병합요법 고려. 선호·비용·저혈당 위험·체중 목표 반영.
HbA1c ≥10% 또는 혈당 ≥300, 케톤/증상인슐린 필요성 평가. DKA/HHS 의심 시 응급실.
ASCVD 고위험/확진GLP-1 RA 또는 SGLT2i 우선 고려.
심부전 또는 CKDSGLT2i 적응증·신장기능·급여 확인. 진행 CKD는 신장내과 협진.
고령/frailty/저혈당 위험과도한 목표 회피. SU/인슐린 시 저혈당 교육 + 완화 목표.

6. 약제별 포인트 — 한국 상품명 포함

약제군주요 상품명(한국)좋은 상황주의
Metformin다이아벡스엑스알, 글루코다운OR정전형적 2형, 비용 부담, 체중 유지위장 부작용 → XR 제형 변경. eGFR <30 금기. B12 결핍 장기 추적.
SGLT2i포시가 10mg, 자디앙 10/25mg, 슈글렛정HF, CKD, ASCVD, 체중/혈압 이득생식기 감염, euglycemic DKA, 수술/금식/급성질환 시 중지. 급여 기준 확인.
GLP-1 RA트루리시티, 오젬픽, 위고비, 마운자로비만, ASCVD 위험, 강한 A1c/체중 감소오심/구토, 췌장염/담낭 병력. 갑상샘 수질암/MEN2 금기. 비급여 시 비용 상담 필수.
DPP-4i자누비아, 트라젠타, 가브스고령, 저혈당 회피, 주사 거부신기능별 용량 조정(리나글립틴 불필요). GLP-1 RA와 병용 이득 부족. 삭사글립틴: 심부전 주의.
SU아마릴, 다이아미크롱MR비용 제한, 빠른 혈당 강하저혈당·체중 증가. 고령/불규칙 식사/CKD 주의. 글리벤클라마이드(다오닐) 노인 금기.
Insulin란투스/트레시바, 노보래피드/휴마로그증상성 고혈당, 케톤, A1c 매우 높음, 1형 의심자가혈당, 저혈당 대처, 주사 교육 필수. 용량조절 계획 수립.
SGLT2i 급여 핵심: Metformin 실패 후 병용은 급여. 심부전(HFrEF/HFpEF) 적응증은 혈당 무관 단독 급여(포시가·자디앙). CKD 적응증은 eGFR 기준 확인. GLP-1 RA 급여는 제한적이므로 처방 전 확인.

7. 의뢰 기준 (Refer)

의뢰처기준
응급실DKA/HHS, 의식변화, 심한 탈수/구토, 급성 흉통/뇌졸중, 중증 감염/괴사성 발 병변.
내분비내과1형/LADA 의심, 반복 케톤, A1c 높고 조절 불량, 복잡한 인슐린 시작, 이차성 당뇨 의심.
안과2형 당뇨 진단 시 안저 평가. 시력저하/비문증/망막병증 의심 시 빠르게.
신장내과eGFR 감소 진행, ACR 지속 상승, 혈뇨/비전형 신장질환, 조절 어려운 고혈압.
혈관/정형/상처발 궤양, 감염, 말초동맥질환, Charcot 의심, 감각저하+변형 동반.
영양/당뇨교육식사 조절 실패, 저혈당 반복, 인슐린/SU 사용, 건강문해력 낮음.

8. 생활교육 핵심 + 환자 설명 스크립트

항목첫날 핵심 메시지
식사단 음료/주스/믹스커피/야식부터 줄이기. 밥·면·빵·과일은 금지보다 양과 시간 규칙.
운동식후 10-20분 걷기부터 시작. 목표: 주 150분 유산소 + 주 2-3회 근력.
체중5-10% 감량만으로 혈당·혈압·지방간·지질 함께 개선 가능.
저혈당 대처식은땀/떨림/두근거림 → 당 15g + 15분 후 재측정.
자가혈당인슐린/SU 사용, 증상성 고혈당, 약 조정 중이면 시간대별 기록 교육.
Sick day구토/탈수/식사 불가 시 SGLT2i·Metformin 임시 중단 + 의료기관 연락.
"당뇨는 단 음식 때문에 생긴 병이 아니라, 몸이 혈당을 처리하는 능력이 떨어진 상태입니다. 치료 목표는 숫자를 낮추는 것뿐 아니라 눈·콩팥·심장·발을 오래 지키는 것입니다. 처음 3개월은 약이 맞는지, 식사/운동이 지속 가능한지, 합병증 검사가 빠지지 않았는지 같이 조정하는 기간입니다. 약 드시다가 속이 불편하거나 혈당이 낮아지는 느낌이 있으면 다음 예약 전이라도 연락 주세요."

9. 미니 케이스 — 한국 1차 진료 실전

케이스상황핵심 접근
Case 140대 직장인, 회사검진 HbA1c 6.8%, 무증상검진일/공복 확인 → FPG+HbA1c 재확인 → eGFR/지질/ACR/발/안저 계획 → 생활중재 4주 → 다이아벡스엑스알 500mg bid 시작 → 3개월 재평가.
Case 2HbA1c 10.8%, 6kg 감소, 구갈/야간뇨, BMI 212형 단정 금지 → 케톤/전해질/산증 당일 평가 → C-peptide/GAD항체 → 인슐린 필요성 평가 → 내분비내과 의뢰.
Case 3HbA1c 8.2%, eGFR 55, ACR 상승, HFrEF 병력포시가 10mg 또는 자디앙 10mg. 심부전 적응증 급여 가능 → ACR 반복 확인 → 신장내과 협진 고려.
Case 460대, 혈압약 복용, HbA1c 7.2%, 혈압 148/92ARB+SGLT2i로 혈압·신장·혈당 동시 이득 고려 → statin 필요성 → Metformin + 트라젠타 병합 옵션.

11. 심플 총정리

진단HbA1c/FPG 기준 알고 명백하지 않으면 재확인. 회사검진 수치 그대로 믿지 말기.
위험케톤·탈수·의식변화·체중감소·구토/복통 → 당일 평가.
검사A1c만 보지 말고 eGFR·ACR·지질·간기능·발·안저를 초진 세트로.
약제Metformin 자동 대신 ASCVD/HF/CKD/비만/저혈당 위험 반영. 상품명 확인.
급여SGLT2i: Metformin 실패 후 병용 또는 HF/CKD 적응증. GLP-1 RA 급여 제한적.
교육단 음료, 식후 걷기, 저혈당 대처, sick day, 발 관리부터 반복.
추적초진 당일 1-4주 + 3개월 예약까지 완료.
