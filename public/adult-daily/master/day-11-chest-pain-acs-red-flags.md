# Day 11. 흉통: ACS red flag, 의원에서 할 것과 바로 보낼 것

작성일: 2026-08-19

## 핵심 결론

의원급 흉통 진료의 목표는 ACS를 완벽하게 확진하거나 배제하는 것이 아니라, **의원에서 안전하게 배제할 수 없는 환자를 빨리 찾아 definitive care가 가능한 응급실로 지체 없이 보내는 것**이다.

- red flag가 있으면 **119 호출을 먼저** 하고 ECG는 가능하면 동시에 시행한다.
- 12-lead ECG는 매우 중요하지만 **정상/비진단적 초기 ECG 한 장으로 ACS를 배제하지 않는다.**
- troponin, 반복 채혈, CXR 등을 의원에서 기다리느라 이송을 늦추지 않는다.
- 법적 리스크 관리는 “많이 검사했다”보다 **당시 위험 판단, 설명, 이송 권고와 실제 disposition을 사실대로 시간 순서에 맞춰 기록**하는 것이 핵심이다.

---

## 1. 첫 3분 triage

1. onset, 현재 지속 여부, 지속시간을 먼저 확인한다.
2. 압박감/조임/무거움, 안정 시 발생, 운동 유발, 팔·턱·등 방사, 식은땀, 호흡곤란, 구역/구토, 실신/presyncope를 묻는다.
3. BP/HR/RR/SpO2/의식상태를 확인한다.
4. shock appearance, pulmonary edema, 심한 빈맥/서맥, 저산소증 여부를 본다.
5. ACS뿐 아니라 acute aortic syndrome, PE, tension pneumothorax 등 lethal chest pain을 동시에 스크리닝한다.
6. red flag가 있으면 **검사 계획보다 disposition을 먼저 결정한다.**

## 2. 바로 응급실/119를 강하게 고려할 소견

### ACS

- 현재 지속되는 압박성/조이는 흉통
- 새로운 안정 시 흉통
- 반복되거나 점점 악화되는 통증
- 팔·어깨·턱·등 방사
- diaphoresis
- dyspnea
- nausea/vomiting
- syncope 또는 presyncope
- known CAD 환자의 새롭거나 악화된 흉통

고령자, 여성, 당뇨 환자에서는 흉통보다 호흡곤란, 피로, 상복부 불편, 오심 등 anginal equivalent로 나타날 수 있다.

### Hemodynamic / respiratory instability

- hypotension
- shock appearance
- altered mentality
- marked hypoxemia
- pulmonary edema
- severe tachycardia/bradycardia 또는 불안정 부정맥 의심

### Acute aortic syndrome

- sudden maximal-at-onset chest/back pain
- pulse/BP asymmetry
- new neurologic deficit
- new AR 의심 소견

### Pulmonary embolism

- sudden dyspnea + pleuritic chest pain
- unexplained hypoxemia/tachycardia
- unilateral leg swelling
- recent surgery/immobility/cancer/VTE history

### Tension pneumothorax

- sudden dyspnea
- unilateral markedly decreased breath sound
- hemodynamic compromise

## 3. 검사 전략: 무엇을 하고 무엇을 안 기다릴 것인가

### 의원에서 바로 할 수 있으면 한다

- V/S + SpO2
- focused history / focused PE
- 12-lead ECG

단, red flag가 이미 충분하다면 **119 호출 및 이송 준비와 병행**한다.

### 전원을 늦추면 하지 않는다

- troponin 결과 대기
- 반복 채혈
- CXR 또는 기타 영상 예약/대기
- 장시간 observation
- “검사 다 해보고 보내기”

**Normal ECG ≠ ACS exclusion.** 초기 ECG가 정상 또는 비진단적이어도 임상적으로 ACS가 배제되지 않으면 응급실 평가가 필요하다.

---

## 4. 약물/처치 실전

- 산소는 routine으로 주지 않고 저산소증/호흡부전이 있을 때 사용한다.
- ACS가 임상적으로 의심되고 aspirin 금기·활동성 출혈이 없으며 acute aortic syndrome이 의심되지 않는 상황에서는 aspirin 투여를 고려할 수 있다.
- 다만 aspirin 투여 여부 때문에 이송을 늦추지 않는다.
- 위장약 또는 진통제에 반응했다고 ACS를 배제하지 않는다.
- 불안정 환자는 의원에서 관찰하지 않는다.

---

## 5. KCD 실무

- **R07.4** 상세불명의 흉통: 의원에서 확진 전 symptom code 후보
- **R07.2 / R07.8** 전흉부통 / 기타 흉통: 실제 기록에 맞춰 사용
- **I20.x / I21.x** 협심증/급성심근경색: 단순 의심만으로 확정 상병처럼 사용하지 말고 실제 진단 근거와 최종 진단에 맞춘다.

상병코드는 실무 후보이며 최종 청구는 실제 진단·검사·차팅과 일치하도록 조정한다.

---

## 6. 법적 리스크를 줄이는 차팅 원칙

차트에는 최소 다음이 보이도록 한다.

1. onset / 현재 지속 여부 / 지속시간
2. 핵심 red flag
3. V/S
4. ACS, aortic syndrome, PE 등 위험감별
5. 의원에서 안전하게 배제할 수 없는 이유
6. 응급실/119 권고와 설명 내용
7. 실제 이송 과정 또는 환자 거부 결과

핵심은 면책 문구가 아니라 **당시 임상 판단 과정이 재현되도록 contemporaneous charting** 하는 것이다.

### 권장 차팅 예시 — 즉시 전원

```text
[Acute chest pain triage]

Onset: ____ / 현재 지속 여부: Y/N / 지속시간: ____
Character/radiation: ____________________
Associated sx: dyspnea __ / diaphoresis __ / N/V __ / syncope-presyncope __
CV risk: CAD __ DM __ HTN __ dyslipidemia __ smoking __ CKD __

V/S:
BP ____/____ mmHg
HR ____ /min
RR ____ /min
SpO2 ____ %
BT ____ ℃

Focused PE:
consciousness __ / heart __ / lung __ / edema __ / pulse asymmetry __ / neuro deficit __

Assessment:
Acute chest pain.
ACS 및 기타 life-threatening cause를 의원급 외래에서 안전하게 배제하기 어렵다고 판단함.
추가적인 의원 내 검사로 definitive evaluation 및 치료가 지연될 가능성이 있어 응급실 즉시 평가가 필요하다고 판단함.

ECG: 시행/미시행, 시간 ____
정상/비진단적 ECG라도 임상적으로 ACS 배제되지 않음.

Plan:
환자에게 심근경색, 치명적 부정맥, 급격한 상태 악화 가능성을 설명하고 즉시 응급실 평가 필요성을 설명함.
119 이송 권고 __:__
119 호출 __:__
출발 __:__

handoff 및 제공자료:
ECG / medication list / allergy / 주요 과거력 / 증상 onset

이송 당시 상태: ____________________
```

## 7. 환자가 119 이송을 거부할 때

가능하면 자가운전은 피하도록 명확히 설명한다. 보호자 차량을 택하더라도 이송 중 악화 가능성을 설명하고, 필요 시 즉시 119를 요청하도록 한다.

```text
ACS 가능성을 배제할 수 없어 119 구급차를 이용한 즉시 응급실 이송을 강하게 권고함.
이동 중 급격한 상태 악화, 치명적 부정맥, 심근경색 및 사망 가능성을 설명함.

환자는 설명 내용을 이해하고 의사결정능력이 있는 상태이나 119 이송을 거부함.
자가운전은 하지 말 것을 설명하고, 보호자 동행 및 증상 악화 시 즉시 119 요청하도록 재차 설명함.

거부 사유: ____________________
보호자 설명 여부/성명: ____________________
설명 시각: ____
퇴실 시각: ____
퇴실 당시 상태: ____________________
```

**Refusal form 하나가 면책을 의미하지 않는다.** 설명 내용, 의사결정능력, 구체적인 거부 내용, 대안 제시를 사실대로 기록한다.

## 8. 외래 평가가 가능한 쪽

다음과 같이 현재 안정적이고 acute red flag가 없는 경우는 외래 경로를 고려할 수 있다.

- 현재 증상이 없음
- hemodynamically stable
- acute change 없음
- 수주~수개월 동일 양상의 stable symptom

이 경우 CAD pretest probability와 위험인자를 평가하고 필요 시 심장내과 외래, CCTA, stress testing 등을 계획한다.

다만 새로 악화된 양상, 안정 시 발생, 빈도/강도 증가가 있으면 acute pathway로 재분류한다.

---

## 9. 의원 운영용 FAST TRACK

접수실 직원이 다음 표현을 들으면 대기시키지 않는다.

- “가슴이 아파요.”
- “가슴이 조여요.”
- “가슴이 답답해요.”
- “숨이 차면서 가슴이 이상해요.”
- “팔이나 턱까지 아파요.”
- “가슴이 아프면서 식은땀이 나요.”

흐름:

**즉시 진료실/처치실 → V/S + SpO2 → 원장 평가 → red flag면 119 먼저 → ECG는 가능하면 동시에**

---

## 10. 법령 포인트

대한민국 「응급의료에 관한 법률」 제11조는 의료인이 해당 의료기관의 능력으로 응급환자에 대해 적절한 응급의료를 할 수 없다고 판단한 경우 **지체 없이 적절한 응급의료가 가능한 다른 의료기관으로 이송**하도록 규정한다.

따라서 의원급에서는 “검사를 더 해볼 수 있었는가”보다 **필요한 환자에게 이송을 지연시키지 않았는가**가 중요하다.
